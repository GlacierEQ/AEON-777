## 📊 MEMORY ORGANIZATION (Smart Tagging)

Every memory gets **multi-dimensional tags** for intelligent retrieval:

### **Dimensions:**

1. **Timeline** (when)
   - `timeline:t0` — Current moment
   - `timeline:t+1d` — Next 24 hours
   - `timeline:t+1w` — Next week
   - `timeline:t+4w` — Next month
   - `timeline:t+3mo` — Medium term
   - `timeline:t+1yr` — Long term

2. **Case Phase** (what stage)
   - `phase:1` — Kalua demand + unsealing + disqualification
   - `phase:2` — Modification + equal protection
   - `phase:3` — Child welfare + restoration
   - `phase:4` — Federal + international escalation

3. **Evidence Type** (what kind of data)
   - `evidence:motion` — Court motions
   - `evidence:exhibit` — Attached exhibits
   - `evidence:court-order` — Judge orders
   - `evidence:transcription` — Audio/video transcripts
   - `evidence:communication` — Emails/documents
   - `evidence:threat-intel` — Judge/HPD movements

4. **Threat Level** (severity)
   - `threat:critical` — Imminent retaliation or fraud escalation
   - `threat:high` — Pattern of judicial bias or HPD coordination
   - `threat:medium` — Suspicious activity requiring monitoring
   - `threat:low` — Baseline case management

5. **Action Type** (what to do)
   - `action:file-motion` — File a court motion
   - `action:serve-document` — Serve on opposing counsel
   - `action:escalate-international` — Submit to UN bodies
   - `action:protective-order` — Emergency protective action
   - `action:evidence-compile` — Organize exhibits
   - `action:analyze-response` — Analyze court response

6. **Owner/Responsible** (who does it)
   - `owner:kekoa` — Kekoa filing personally
   - `owner:casey` — Casey coordinating
   - `owner:automation` — Autonomous system
