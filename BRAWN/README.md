# 💪 BRAWN — ECHO Execution Spiral

The **BRAWN** is the movement and function side of AKOS. It receives a Brain-approved route and turns it into an organized, traceable work package.

ECHO remains a universal excellence engine. This repository's `ECHO_CONFIG.json` supplies the case-specific specialization; the engine itself is not a legal application.

## Brawn jobs

- Assemble source-linked drafts and exhibit sets
- Validate filenames, required sections, links, and package completeness
- Hash and record evidence packages without changing source material
- Stage motion and correspondence packages for user review
- Track handoffs, outputs, and blockers
- Return results to the Brain with pointers and a clear status

## Non-negotiable gates

- JEFS filing is prepared and reviewed by the user; ECHO does not file autonomously.
- Service, publication, evidence release, or external escalation requires user approval.
- Brawn never overwrites source evidence. New derivatives receive their own path and provenance note.
- Every output points back to the Brain route and the source files used.
